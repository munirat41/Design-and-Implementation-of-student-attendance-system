# Design-and-Implementation-of-student-attendance-system
Making attendance easy to record 
About the Project

The Student Attendance Management System is a web-based application designed to make recording and managing student attendance easier.

The system allows users to register students, create multiple course sessions, and record attendance for each session.

Features

- Register students with their names and matric numbers.
- Create multiple course sessions.
- Automatically display registered students in each course.
- Mark students as present or absent.
- Save attendance records using Local Storage.
- View attendance statistics.
- Responsive user interface.

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

- "index.html" – Application structure.
- "style.css" – Application styling.
- "style.js" – Application functionality.

How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Start registering students and recording attendance.

Data Storage

The application uses the browser's Local Storage to save student records, course sessions, and attendance information.
